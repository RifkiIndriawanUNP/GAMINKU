About gaminku

gaminku adalah platform pencarian dan database game yang dikembangkan oleh Mohammad Rifki Indriawan (NIM: 20240040102). Platform ini menggunakan RAWG Video Games Database API untuk menyediakan informasi lengkap tentang ribuan game dari berbagai platform dan genre.

Pengguna dapat mencari game berdasarkan nama, melihat detail lengkap termasuk rating, platform, genre, dan screenshot, menyimpan game ke dalam daftar favorit dan wishlist, serta menelusuri game berdasarkan huruf pertama nama melalui fitur A-Z.

Proyek ini dibuat sebagai implementasi pembelajaran pengembangan web full-stack dengan teknologi modern seperti Node.js, Express.js, MySQL, dan integrasi API eksternal.
